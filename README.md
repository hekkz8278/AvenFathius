AvenFathius - Liquid Glass Buttons & Images Gallery Motion

A modern web app featuring interactive **Liquid Glass buttons** inspired by Apple's iOS 26 design language. Smooth, refractive, and responsive glass effects built purely with HTML, CSS, and JavaScript.

 ✨ Features

- Liquid Glass Effect - Realistic frosted glass with refraction and distortion
- Interactive Buttons - Hover, press, and ripple animations
- Dynamic Background - Glass reacts to background content in real-time
- Responsive Design - Works on desktop and mobile
- Lightweight - No frameworks, pure HTML / CSS / JS
- Customizable - Easy to change color, blur, radius, and intensity
